## 💡 О проекте

**GeoHide DNS Manager** — автономная настольная утилита для Windows с современным тёмным интерфейсом на базе **CustomTkinter**. Она решает проблему доступа к сервисам **Google Gemini**, **ChatGPT**, **Claude** и зарубежным AI-инструментам через инфраструктуру **GeoHideDNS**.

### 🌟 Ключевые фичи:
- 🎯 **Изолированный Smart Proxy**: Маршрутизирует запросы к Gemini **только** для `Antigravity IDE`, `Antigravity 2.0 Desktop` и консоли `agy CLI`. Системный DNS и `hosts` не затрагиваются — ваши браузеры, игры, Telegram и мессенджеры продолжают летать напрямую на максимальной скорости вашего провайдера!
- 🌐 **Глобальный режим**: Возможность в 1 клик переключить системные DNS всех активных адаптеров и системный файл `hosts`.
- 📌 **Сворачивание в системный трей (`pystray`)**: Нажатие на крестик `[X]` не обрывает прокси, а прячет окно в область уведомлений возле часов Windows.
- 🚀 **Автозапуск с Windows**: Опция запуска приложения вместе с ОС в скрытом режиме (`--minimized`) прямо в трей.
- ⚠️ **Умное предупреждение и перезапуск**: Если при активации прокси Antigravity уже открыта, приложение предупредит и предложит мягкий перезапуск IDE в 1 клик для немедленного вступления настроек в силу.
- 🛡️ **Полная анонимность и безопасность**: Нулевая привязка к конкретным пользователям — все пути и системные переменные определяются динамически.

## 🛠 Стек технологий

- **Язык:** Python 3.11+
- **Интерфейс (GUI):** `customtkinter` (Modern Dark / Blue)
- **Фоновый трей:** `pystray`
- **Обработка графики:** `Pillow` (PIL)
- **Сетевое ядро:** Асинхронный HTTP/HTTPS CONNECT туннель (`local_proxy.py`)
- **Интеграция с Windows:** `winreg` (реестр для переменных среды и автозапуска), `SendMessageTimeoutW` (`WM_SETTINGCHANGE`), PowerShell, `ctypes`
- **Компиляция:** `PyInstaller` (автономный `.exe` без окна консоли)

## 🧩 Архитектура модулей

### 1. `app.py`
Управляет жизненным циклом приложения, графическими карточками состояния сети, переключением между режимами «Только Antigravity» и «Вся Windows», а также иконкой системного трея. При закрытии окна прячет интерфейс в трей, гарантируя бесперебойную работу прокси в фоне.

### 2. `local_proxy.py` (Smart Proxy)
Локальный легковесный прокси-сервер на `127.0.0.1:8899`:
- Перехватывает `CONNECT` запросы.
- Домены Google AI и Gemini (`gemini.google.com`, `generativelanguage.googleapis.com`, `*.googleapis.com`, `*.openai.com`, `*.anthropic.com`) туннелирует на проверенные рабочие IP GeoHide (`193.233.112.68`, `193.233.112.88`, `193.233.112.67`). Так как исходный заголовок TLS SNI сохраняется, GeoHide корректно маршрутизирует трафик без SSL-ошибок.
- Все остальные сайты туннелируются напрямую через обычное интернет-соединение.

### 3. `antigravity_config.py`
- Для **Antigravity IDE**: настраивает `%APPDATA%\Antigravity\User\settings.json` (`"http.proxy": "http://127.0.0.1:8899"`).
- Для **Antigravity 2.0** и **CLI (`agy`)**: устанавливает пользовательские переменные окружения `HTTP_PROXY`, `HTTPS_PROXY`, `ALL_PROXY` в `HKCU\Environment` и транслирует системное событие `WM_SETTINGCHANGE`.
- Отслеживает PIDs процессов `Antigravity.exe`, `language_server.exe` и `agy.exe`.
- Обеспечивает плавный перезапуск Antigravity при подтверждении пользователем.

### 4. `autostart.py`
Управляет ключом автозагрузки в реестре `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`, запуская приложение при старте Windows с параметром `--minimized`.

### 5. `geohide_core.py`
Глобальный режим: опрос сетевых карт через PowerShell (`Get-NetAdapter`), установка DNS GeoHide, безопасная врезка блока правил в системный файл `hosts` по маркерам `# === GEOHIDE DNS START ===`, сброс кэша DNS (`ipconfig /flushdns`) и замер времени отклика Gemini в миллисекундах.

## 🚀 Установка и запуск

### Запуск из исходников:
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/manka81/open-antigravity.git
   cd open-antigravity
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```bash
   python app.py
   ```
   *Или дважды кликните по `run.bat`.*

### Сборка автономного .EXE файла (без консоли):
Для сборки готового бинарника выполните:
```bash
pyinstaller --noconsole --onefile --icon=icon.ico --add-data "icon.ico;." --add-data "icon.png;." --name="GeoHideManager" app.py
```
Готовый файл появится в папке `dist/GeoHideManager.exe`!
