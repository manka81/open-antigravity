## 💡 О проекте

**GeoHide DNS Manager** — мощная автономная настольная утилита для Windows с современным тёмным интерфейсом на базе **CustomTkinter**. Она комплексно решает любые проблемы доступа к сервисам **Google Gemini**, **Antigravity AI**, **ChatGPT**, **Claude** и зарубежным AI-инструментам через инфраструктуру **GeoHideDNS**, а также полностью снимает региональные и аккаунтные блокировки Google Antigravity (ошибка 400 / `ineligible`).

---

## 🌟 Ключевые возможности

1. 🎯 **Изолированный Smart Proxy (Только для Antigravity)**:
   - Маршрутизирует запросы к Gemini **исключительно** для `Antigravity IDE`, `Antigravity 2.0 Desktop` и консоли `agy CLI`.
   - Системный DNS Windows и файл `hosts` не затрагиваются — ваши браузеры, игры, Telegram и мессенджеры продолжают работать напрямую на максимальной скорости вашего провайдера!
   - Автоматический обход OAuth2: запросы авторизации токенов (`oauth2.googleapis.com`) всегда направляются напрямую во избежание сбоев авторизации.

2. 🔓 **Разблокировка любых Google аккаунтов (Снятие ошибки 400 / ineligible)**:
   - Устраняет ошибку `User location is not supported` (HTTP 400) и блокировку аккаунтов без ожидания в waitlist.
   - Побайтовое безопасное переименование дескриптора Protobuf `ineligible` → `inexigible` в бинарниках `language_server.exe` и `agy.exe`.
   - Длина строки (10 байт) строго сохраняется, структура PE-файлов, смещения и таблицы импорта остаются интактными.
   - Поддержка создания резервных копий (`.ag_bak`) и отката к заводскому состоянию в 1 клик.
   - Защита от непреднамеренного сброса сессий: никаких принудительных закрытий без подтверждения пользователем через диалоговое окно.

3. 🌐 **Глобальный режим (Для всей Windows)**:
   - Возможность в 1 клик переключить системные DNS всех активных сетевых карт и системный файл `hosts`.
   - Автоматическая очистка DNS-кэша (`ipconfig /flushdns`) и замер времени отклика Gemini.

4. 📌 **Работа в системном трее (`pystray`)**:
   - Нажатие на крестик `[X]` не обрывает прокси, а сворачивает окно в область уведомлений Windows.
   - Двойной клик или пункт контекстного меню разворачивает окно обратно.

5. 🚀 **Автозапуск вместе с Windows**:
   - Управление автозагрузкой через реестр `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.
   - Поддержка тихого запуска с ключом `--minimized` прямо в трей.

6. 🛡️ **Полная анонимность и безопасность**:
   - 0% персональных данных в коде и конфигурациях. Все пути (`%LOCALAPPDATA%`, `%APPDATA%`, `%PROGRAMFILES%`) вычисляются динамически на любой машине.

## 🛠 Стек технологий

- **Язык программирования:** Python 3.11+
- **Графический интерфейс (GUI):** `customtkinter` (Modern Dark / Blue theme)
- **Фоновый системный трей:** `pystray`
- **Обработка графики:** `Pillow` (PIL)
- **Сетевое ядро:** Асинхронный HTTP/HTTPS CONNECT туннель (`local_proxy.py`)
- **Низкоуровневый патчер:** Бинарный сканер и парсер Protobuf-сигнатур (`account_patcher.py`)
- **Интеграция с Windows:** `winreg` (реестр для переменных среды и автозапуска), `SendMessageTimeoutW` (`WM_SETTINGCHANGE`), PowerShell, `ctypes`
- **Сборка бинарника:** `PyInstaller` (автономный `.exe` без окна консоли)

## 🧩 Архитектура модулей

### 1. `app.py`
Координирует графический интерфейс, фоновые потоки мониторинга, карточки управления режимами:
- Переключение между изолированным Smart Proxy и глобальным DNS.
- Карточка статуса и разблокировки аккаунтов с динамическими бейджами (`🟢 Все аккаунты разрешены`, `🟡 Частично`, `⚪ Стандартный`).
- Обработка сворачивания в трей (`pystray`) при нажатии на крестик `[X]`.
- Модальное диалоговое окно `CustomConfirmDialog` с запросом на перезапуск Antigravity только при необходимости.

### 2. `account_patcher.py` (Снятие блокировок аккаунтов)
- Сканирует систему на наличие исполняемых файлов `language_server.exe`, `language_server_windows_x64.exe` и `agy.exe` в `%LOCALAPPDATA%`, `%PROGRAMFILES%` и `PATH`.
- Выполняет побайтовую замену `ineligible` → `inexigible`. Так как десериализатор Go/Protobuf больше не находит в ответе сервера запрещающий флаг `ineligible`, аккаунт признаётся валидным и получает полный доступ к AI-моделям.
- Автоматически создает резервную копию `.ag_bak` перед первым патчем.
- Обеспечивает функцию `unpatch_all()` для мгновенного отката изменений.
- Атомарная запись через временный файл `.agtmp` исключает повреждение исполняемого файла при сбое питания или блокировке.

### 3. `local_proxy.py` (Smart Proxy)
Локальный легковесный прокси-сервер на `127.0.0.1:8899`:
- Перехватывает `CONNECT` запросы от IDE и консоли.
- Домены авторизации Google OAuth2 (`oauth2.googleapis.com`, `accounts.google.com`, `identitytoolkit.googleapis.com`, `securetoken.googleapis.com`) направляет **напрямую**, устраняя ошибку обрыва токена.
- Запросы к AI-моделям (`gemini.google.com`, `generativelanguage.googleapis.com`, `*.googleapis.com`, `*.openai.com`, `*.anthropic.com`) туннелирует на серверы GeoHide (`193.233.112.68`, `193.233.112.88`, `193.233.112.67`) с сохранением исходного TLS SNI.
- Все остальные сетевые подключения направляются напрямую через интернет-провайдера.

### 4. `antigravity_config.py`
- Для **Antigravity IDE**: синхронизирует `%APPDATA%\Antigravity\User\settings.json` (`"http.proxy": "http://127.0.0.1:8899"`).
- Для **Antigravity 2.0** и **CLI (`agy`)**: устанавливает пользовательские переменные окружения `HTTP_PROXY`, `HTTPS_PROXY`, `ALL_PROXY` в `HKCU\Environment` и широковещательно уведомляет систему через `WM_SETTINGCHANGE`.
- Отслеживает PIDs процессов `Antigravity.exe`, `language_server.exe` и `agy.exe`.

### 5. `autostart.py`
Управляет записью реестра `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`, обеспечивая автоматический запуск утилиты в трей при входе пользователя в систему.

### 6. `geohide_core.py`
Глобальный режим: опрос сетевых карт через PowerShell (`Get-NetAdapter`), установка DNS GeoHide, безопасная врезка блока правил в системный файл `hosts` по маркерам `# === GEOHIDE DNS START ===`, сброс кэша DNS (`ipconfig /flushdns`) и замер времени отклика Gemini в миллисекундах.

## 🚀 Установка и запуск

### Вариант 1: Запуск готового .EXE (Рекомендуется)
Скачайте готовый автономный файл `GeoHideManager.exe` из раздела [Releases](https://github.com/manka81/open-antigravity/releases) и запустите его. Установка Python не требуется!

### Вариант 2: Запуск из исходников:
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/manka81/open-antigravity.git
   cd open-antigravity
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```bash
   python app.py
   ```
   *Или запустите `run.bat`.*

### Сборка автономного .EXE файла:
Для сборки готового бинарника выполните чистый скрипт сборки:
```cmd
build_release.bat
```
Либо вручную через PyInstaller:
```bash
pyinstaller --noconsole --onefile --clean --icon=icon.ico --add-data "icon.ico;." --add-data "icon.png;." --add-data "geohide_domains.json;." --name="GeoHideManager" app.py
```
Готовый исполняемый файл появится в папке `dist/GeoHideManager.exe`!
