# GeoHide DNS Manager 🛡️⚡

Современное настольное приложение на Python для Windows с графическим интерфейсом на базе CustomTkinter, предназначенное для быстрого и безопасного переключения и диагностики статуса обхода географических ограничений (Google Gemini, ChatGPT, зарубежные AI-сервисы) через проект **GeoHideDNS**.

Приложение поддерживает **два независимых режима работы**:
1. 🎯 **Изолированный режим (Antigravity IDE, Antigravity 2.0 и CLI `agy`)** — маршрутизирует трафик только целевых инструментов разработчика через локальный Smart Proxy (`127.0.0.1:8899`). Системный файл `hosts` и общесистемный DNS Windows остаются чистыми и не затрагиваются (браузеры, игры, мессенджеры и другие программы работают через обычного провайдера на максимальной скорости). При включении определяет запущенные экземпляры Antigravity и выводит диалоговое окно с предупреждением и предложением перезапуска.
2. 🌐 **Глобальный режим (Для всей Windows)** — классическое переключение системных DNS-серверов сетевых карт и файла `hosts` (`C:\Windows\System32\drivers\etc\hosts`).

## 🛠 Стек технологий

- **Язык программирования:** Python 3.11+
- **Графический интерфейс (GUI):** `customtkinter` (Modern Dark/Blue Theme)
- **Работа с изображениями:** `Pillow` (PIL)
- **Сетевое взаимодействие:**
  - `local_proxy.py`: встроенный асинхронный HTTP/HTTPS CONNECT туннель (`select`, `socket`)
  - `urllib.request` для загрузки списков хостов и проверки связи
  - `subprocess` для вызова системных утилит Windows
- **Системные вызовы Windows:**
  - `winreg` (реестр `HKEY_CURRENT_USER\Environment` для установки `HTTP_PROXY`, `HTTPS_PROXY`, `ALL_PROXY`)
  - `SendMessageTimeoutW` (широковещательное системное оповещение `WM_SETTINGCHANGE` для мгновенного применения переменных среды)
  - `PowerShell` (командлеты `Get-NetAdapter`, `Get-DnsClientServerAddress`, `Set-DnsClientServerAddress`)
  - `cmd.exe` / `wmic` (`taskkill`, `ipconfig /flushdns`, `ping`)
  - `ctypes.windll.shell32` (проверка прав администратора `IsUserAnAdmin` и UAC-повышение `ShellExecuteW`)
- **Векторная графика:** SVG (`icon.svg`) и иконки высокого разрешения (`icon.ico`, `icon.png`)

## 🧩 Назначение модулей и архитектура данных

### 1. `app.py`
- Обеспечивает работу переключателя режимов (`CTkSegmentedButton`):
  - **"🎯 Только Antigravity (IDE, 2.0, agy CLI)"**
  - **"🌐 Вся Windows (Глобальный)"**
- В изолированном режиме запускает/останавливает `local_proxy.py`, вызывает `antigravity_config.py` для комплексной настройки IDE и переменных среды.
- **Интерактивный диалог перезапуска (`RestartConfirmDialog`)**: если при включении прокси обнаруживается запущенный процесс `Antigravity.exe` / `language_server.exe`, открывает всплывающее окно с предупреждением:
  - Кнопка **«🚀 Перезапустить сейчас»** — выполняет чистое закрытие и повторный запуск `Antigravity.exe` с новыми переменными среды.
  - Кнопка **«⏱️ Перезапустить позже»** — оставляет приложение работать, изменения вступят в силу при следующем ручном запуске.
- Ведет детальный журнал событий с потокобезопасным выводом сообщений от прокси и сетевых команд.
- Осуществляет периодический автоопрос состояния (каждые 12 секунд).

### 2. `local_proxy.py` (Изолированный Smart Proxy)
- Локальный прокси-сервер на `127.0.0.1:8899`.
- Анализирует домены в HTTPS CONNECT запросах:
  - Если запрос идет к целевым сервисам (`gemini.google.com`, `generativelanguage.googleapis.com`, `*.googleapis.com`, `*.openai.com`, `*.anthropic.com`): прозрачно устанавливает TCP-туннель к рабочим IP GeoHide (`193.233.112.68`, `193.233.112.88`, `193.233.112.67`). Так как TLS SNI заголовок передается без изменений, GeoHide проксирует трафик без сертификатных ошибок.
  - Если запрос идет к любым другим сайтам (GitHub, npm, расширения): туннелирует напрямую через обычный интернет провайдера.
- Работает полностью внутри пользовательского пространства без необходимости прав Администратора.

### 3. `antigravity_config.py`
- **Antigravity IDE**: настраивает `C:\Users\manka\AppData\Roaming\Antigravity\User\settings.json`:
  ```json
  "http.proxy": "http://127.0.0.1:8899",
  "http.proxySupport": "on",
  "http.proxyStrictSSL": false
  ```
- **Antigravity 2.0 Desktop и CLI (`agy.EXE`)**:
  - Управляет ключом реестра `HKEY_CURRENT_USER\Environment`: устанавливает `HTTP_PROXY`, `HTTPS_PROXY`, `ALL_PROXY`, `http_proxy`, `https_proxy` со значением `http://127.0.0.1:8899`.
  - Отправляет широковещательное сообщение Windows `WM_SETTINGCHANGE`, благодаря чему любые терминалы с `agy` и процессы 2.0 мгновенно подхватывают прокси без перезагрузки системы.
  - При отключении начисто удаляет эти переменные из реестра.
- **Управление процессами**:
  - `get_target_processes_status()` — определяет PIDs `Antigravity.exe`, `language_server.exe` и `agy.exe`.
  - `is_any_antigravity_running()` — быстро проверяет наличие активных сессий.
  - `restart_antigravity()` — корректно останавливает процессы и заново запускает `Antigravity.exe`.

### 4. `geohide_core.py` (Глобальное ядро)
- Сканирует активные сетевые адаптеры через PowerShell.
- Читает системный файл `C:\Windows\System32\drivers\etc\hosts`.
- Внедряет/удаляет блок GeoHide по маркерам `# === GEOHIDE DNS START ===` и `# === GEOHIDE DNS END ===`, сохраняя остальные пользовательские записи в `hosts`.
- Выполняет сброс кэша (`ipconfig /flushdns`) и проверку пинга.

### 5. `icon.svg`
- Векторная SVG-иконка: темный фон, щит безопасности, глобус и неоновая молния.

## 🚀 Установка и запуск

### Требования
- ОС Windows 10 / Windows 11
- Установленный Python 3.10+

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Запуск приложения
Запустите файл [run.bat](file:///C:/Users/manka/.gemini/antigravity/scratch/geohide_switcher/run.bat) двойным кликом мыши или выполните команду:
```bash
python app.py
```
